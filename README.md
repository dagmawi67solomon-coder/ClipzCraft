# ClipCraftMedia — site prêt à envoyer

Ouvre `index.html` dans un navigateur pour prévisualiser le site.

## Structure

- `index.html` — page principale
- `css/styles.css` — styles de la page
- `assets/logo.png` — logo fourni, détouré sur fond transparent (également utilisé comme favicon)
- `assets/images/` — images locales du hero et de la section présentation
- `assets/videos/clip-1.mp4`, `clip-2.mp4`, `clip-3.mp4` — les trois vidéos fournies

Les vidéos sont référencées avec des chemins relatifs : il faut envoyer le dossier complet (ou le ZIP), pas seulement `index.html`.
